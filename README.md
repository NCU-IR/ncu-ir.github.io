# 校務研究公開資訊

國立中央大學校務研究辦公室的 Tableau 圖表入口網站：https://ncu-ir.github.io/

## 平常要改內容：只改雲端試算表

分類、網頁表冊名稱、選單簡稱、顯示順序，全部由 Google 雲端的「公開資料表冊名稱與網址」決定。
改完存檔，網頁重新整理就會更新，**不用動這裡的任何檔案**。

- 「分類」欄填 `其他`、`高教深耕`、`世界大學排名` 的，不會出現在網站上
- 列的順序＝選單的順序
- 「網址」「尺寸」欄不要改

## 自動更新

每天台灣時間 02:00，`.github/workflows/update.yml` 會去 Tableau Public 抓每張圖的發佈更新日與點閱數，更新 `meta.js`、`data.js`。
要馬上更新：上方 **Actions** → 「每日更新點閱數與發佈日」→ **Run workflow**。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 網頁本體 |
| `meta.js` | 點閱數、發佈更新日（程式產生） |
| `data.js` | 雲端試算表的備份，讀不到雲端時使用（程式產生） |
| `scripts/update.py` | 每日更新程式 |
| `tiles_blue/`、`logo_white.png`、`操作說明.pdf` | 首頁圖示、LOGO、圖表操作說明 |

## 換人接手

組織 **People** 頁面邀請新成員、移除舊成員即可，網站與網址不受影響。
